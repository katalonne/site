Contestare

În mediul Delphi 7 - există module care permit implementarea unui HTTP CGI Server pe sistemul de operare Windows.

Câteva soluții:

  1. Borland WebSnap
  2. Synopse
  3. Implementare customizata prin sockete

Felix John - programator la Institutul Pascal din Paris a implementat un CGI HTTP Server care l-a făcut public în mediul online. Acest server permite servirea fișierelor catre un client HTTP.

Aici este un Proof of Concept (Gitlab Repo) care servește fișierele pentru proiectul Travel-Agency-2021.
Link pentru Descărcare Zip.

Executabilul se află în directoriul web/_exe/p_cgi_web_server.exe.

Aici putem observa serverul rulînd pe portul 80.

Cerințe de Sistem:
  • Sistem de operare Windows
  • Borland Delphi 7 (opțional)

Notă: Mai multe de atît, chiar și o companie din Republica Moldova a făcut open-source un HTTP CGI Server. Autorul este chiar directorul - Maxim Masiutin.
Compania: RITLABS Srl
Modulul: TINYWEB Server
